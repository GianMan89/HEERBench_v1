# Military expert review

Review complete chains rather than question rows in isolation. This package provides a fully authored candidate corpus. Structural validation checks its record consistency. Military validation of the new content is a distinct next activity.

1. Open **Chains** and select a scenario and topic. Follow its A, B and F IDs into **Questions**.
2. Read the relevant passages in **Sources**, then judge whether A preserves source status, B adds a justified interpretation, and F produces a concrete consequence supported by that interpretation.
3. Inspect **Dependencies**. Confirm each joint parent set, identify any decorative or missing premise and consider whether the counterfactual expectation is plausible. Source access remains available, so a graph link is not a forced cognitive path.
4. Inspect **Criteria** and **ErrorChecks**. Split any remaining independent requirements, remove over-prescriptive details and add defensible alternatives. Check that omission of a required qualification and commission of a material error are represented correctly.
5. Inspect **ItemLedger** for partial reuse and conversion-stage exclusions. An excluded original can be restored if a defensible complete chain is supplied. A partially reused item must not be described as fully covered.
6. Record **Accept**, **Revise** or **Reject** and an exact comment. Review all affected memberships after changing a shared question.

For a rigorous annotation study, retain each reviewer's initial decisions separately before adjudication and predefine the units and labels for agreement analysis. The current workbook does not fabricate independent annotations from the earlier joint screening review. It supplies a single decision/comment field per review record for practical first adjudication.

Suggested rejection reasons are unsupported reference, retrieval labelled as interpretation, non-concrete consequence, leading question, missing or decorative dependency, incomplete accepted alternatives, and invalid source/authority assumption. These reasons should describe the actual defect rather than function as a numerical risk score.

After adjudication, freeze question wording, references and graph version before model comparison. A small model pilot can then detect ambiguity, answer leakage, scoring disagreement and unnecessary difficulty from formatting. It does not replace the military validation.
